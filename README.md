## Bir bakışta Trace

Dağınık başvuruları tek yerde gör. Yaklaşan işleri belirle, kayıtlı ilan/CV
değerlendirmelerini karşılaştır ve hangi yetkinliklere odaklanacağını incele.
**Aciliyet ve eşleşme ayrı gösterilir:** acil bir iş, en iyi eşleşmen olmayabilir.

<a href="https://atalay9807.github.io/trace-job-tracker/app.html#/ana"><img src="docs/img/readme/ana-2026-09-20.jpg" alt="Trace ana sayfası: başvuru özeti, yaşam döngüsü ve bugün yapılacak işler" width="100%"></a>

> **Bu bir demo.** Örnek profil ve anonimleştirilmiş kayıtlar kullanılır; kişisel
> hesaba bağlanmaz. Eşleşmeler kayıtlı değerlendirmelerden hesaplanır, kurslar
> simülasyondur. Görseller 20 Eylül 2026'da yayındaki demodan alınmıştır.

## AI ile geliştirme

Trace, gerçek bir iş arama ihtiyacından doğan **AI destekli geliştirme portföyü**.
Ürün yönünü ve öncelikleri **Atalay Denizer** belirliyor. İlk sürüm Claude Code ile
geliştirildi; Claude teknik liderliği, uygulamayı ve entegrasyonu üstlenirken
Codex bağımsız inceleme, test ve tamamlayıcı geliştirmelerle katkı sağlıyor.
Değişiklikler GitHub geçmişi ve pull request'ler üzerinden incelenebilir.

Depoda **9 ajan rolü ve 7 skill** bulunuyor. İlan çözümleyici ile eşleştirici
ayrı görevler üstlenir; profil ve geçmiş sonuçlara bakan rol önericilerinin
kanıt kaynakları da ayrıdır. Ajanlar öneri üretir, seçilen tek yazıcı kaydı
kaydeder; şema ve sayısal hesaplar kodla denetlenir.

Bu rol tanımları web demosuna bağlı çalışan bir AI servisi veya ölçülmüş model
başarısı anlamına gelmez. Çalışma yaklaşımı ve katkılar:

[Claude talimatları](CLAUDE.md) · [Codex talimatları](AGENTS.md) · [Ortak çalışma](docs/ORTAK_CALISMA.md) · [Codex çalışma merkezi](https://github.com/atalay9807/trace-job-tracker/issues/4)

<details>
<summary><strong>Mimari, dosya haritası ve tasarım sistemi</strong></summary>

Yetkilendirilmiş veri toplama ve ajan değerlendirmeleri JSON kayıtlarını besler.
Python çekirdeği bu kayıtları doğrular; aciliyet, eşleşme ve raporları hesaplar.
Derleyici, demo verisini HTML şablonuna gömerek web arayüzünü üretir.

| Yol | Sorumluluk |
|---|---|
| `data/` | Yedi JSON dosyasında demo başvurular, profil ve destekleyici kataloglar |
| `src/veri.py` | Veri kaynağı seçimi, şema denetimi, ortak tarih/durum tanımları |
| `src/pipeline.py` | Aciliyet, hatırlatma, Markdown/text/CSV/JSON raporu |
| `src/match.py` | Eşleşme boyutlarını toplama ve segmentleme |
| `src/eslesme_kontrol.py` | Ajan önerisini kaydetmeden önce şema ve hesap kontrolü |
| `src/insights.py` | Sekiz analiz ve eğitim planı |
| `src/dashboard.template.html` | Altı sayfalı arayüzün kaynağı |
| `src/build_dashboard.py` | Veri gömme ve demo üretimi |
| `tests/` | Python regresyonları ve DOM davranış testleri |
| `.claude/` | Ajan rol tanımları ve görev kuralları |
| `site/` | Tanıtım sayfası ve üretilmiş demo |
| `web-live/` | Ayrı web uygulamasının Faz 1 planı |

`site/app.html`, `site/_artifact.html` ve `reports/pano.html` türetilmiş
çıktılardır. Arayüz değişikliği şablonda yapılır ve yeniden üretilir.

Tasarımda **indigo** markayı, **mor tonları** eşleşmeyi, **kırmızı/kehribar/yeşil**
süreç durumunu temsil eder. Tema ve kontrast ayrıntıları [teknik dokümanda](docs/TEKNIK.md).

</details>

<details>
<summary><strong>Geliştiriciler için çalıştırma ve test</strong></summary>

Web demosunu denemek için kurulum gerekmez. Kod üzerinde çalışmak isteyenler
Python 3.11+ kullanabilir; hesaplama çekirdeğinin harici Python bağımlılığı yoktur.

```bash
git clone https://github.com/atalay9807/trace-job-tracker.git
cd trace-job-tracker

python3 src/veri.py
python3 src/pipeline.py --format markdown
python3 src/match.py
python3 src/insights.py
python3 src/build_dashboard.py --site
python3 -m unittest discover -s tests -v
```

Arayüz geliştirme testleri Node 20+ ve jsdom kullanır:

```bash
npm ci --ignore-scripts
npm test
git diff --check
```

Bu kontroller bulutta veya [GitHub Actions](https://github.com/atalay9807/trace-job-tracker/actions)
üzerinde çalışabilir. DOM testleri gerçek Gmail/model erişimini veya görsel
tarayıcı düzenini doğrulamaz.

</details>

<details>
<summary><strong>Demo verisi, gizlilik ve ölçüm sınırları</strong></summary>

- **Örnek kimlik:** Kerem Aydın demo profildir; proje sahibi Atalay Denizer'dir.
- **Özel veri:** Gerçek kayıtlar açık deponun dışında tutulur ve `TRACE_DATA` ile
  seçilir. Seçilen dış veri eksikse demo veriye sessizce dönülmez. Veri klasörü
  bütün script ve ilgili ajanlar için aynı olmalıdır.
- **Yayın sınırı:** Statik HTML veriyi içinde taşır ve kimlik doğrulamaz. Özel veri
  içeren pano herkese açık sunucuya yüklenmez; `--site` yalnızca depo demosunu
  kabul eder. Kişisel başvuru/e-posta aksiyonları kamuya açık HTML'e eklenmez.
- **CSV:** Görünen sonuçların dışa aktarımıdır; yedekleme veya içe aktarma biçimi
  değildir ve kaynak JSON'u değiştirmez.
- **Eşleşme:** `match.py` CV metnini analiz etmez; kayıtlı boyutları toplar.
  Bilinmeyen puan `null` kalır. Kaynak ilan metni olmayan geçmiş puanlar,
  doğrulanmış model başarısı sayılmaz.
- **Red gerekçesi:** İlan/profil farkından çıkarılan bir eksik, şirketin kişiyi
  o nedenle reddettiğini kanıtlamaz.
- **Yanıt ve aşamalar:** İlk yanıt `first_response` ile ölçülür; `last_contact`
  onun yerine kullanılamaz. Anlık aşamalar, olay geçmişi olmadan ardışık
  dönüşüm oranı gibi sunulmaz. Görüntülenen tüm ilanların sayısı bilinmez.
- **Eğitim:** Kurs başlıkları, fiyatlar ve kayıt akışı örnektir; gerçek kurs
  servisine bağlantı bulunduğu anlamına gelmez.

Veri akışı ve doğrulama kuralları [ortak çalışma sözleşmesinde](docs/ORTAK_CALISMA.md).

</details>
